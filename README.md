# 📚 BD Universe

BD Universe est une landing page moderne créée dans le cadre du projet Landing Page de The Odin Project.

Ce site met en avant une boutique fictive de bandes dessinées où les visiteurs peuvent découvrir différentes collections, notamment des comics, mangas et romans graphiques.

## 🚀 Fonctionnalités

- Design moderne réalisé avec HTML5 et CSS3
- Mise en page entièrement réalisée avec Flexbox
- Section Hero avec image principale
- Présentation des collections populaires de BD
- Section témoignage/citation
- Appel à l'action (Call To Action)
- Footer simple et élégant

## 🛠️ Technologies utilisées

- HTML5
- CSS3
- Flexbox
- Google Fonts (Roboto)

## 📸 Aperçu

Cette landing page présente :

- Une navigation claire
- Une section d'accueil attrayante
- Des images illustrant différentes catégories de bandes dessinées
- Un design inspiré de la maquette officielle de The Odin Project

## 🎯 Objectifs du projet

Ce projet a permis de pratiquer :

- La structure HTML sémantique
- Le positionnement avec Flexbox
- La mise en forme avec CSS
- L'organisation d'une page web complète
- Les bonnes pratiques Git et GitHub
